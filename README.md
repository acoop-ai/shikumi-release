# shikumi-release（しくみの辞書・画面の枠）

このリポジトリは **GitHub Pages で配る「画面の枠」だけ**です。

- 🔴 **辞書の中身（用語・知恵・システム別の診断・システム地図）は、ここに置きません。**
  中身は GAS が、会社指定の4ドメインの Google ログインを毎回確かめてから返します。
- 公開の場所に中身を置くと、ログインを丸ごと迂回する裏口になります（一時的なプレビューでも禁止）。
- ここにあるファイルは、辞書の台本（`build.py`）が作ります。**手で直さない**でください（次に作ると上書きされます）。
- 作るときは、社内のシステム名などが紛れ込んでいないかを台本が検査し、見つかったら何も書かずに止まります。
